## 🔧 如何修改当前环境

### 方法1：使用启动脚本（推荐）

#### Windows开发环境
直接运行：
```batch
start-dev.bat
```

#### Windows生产环境
1. 编辑 `start-prod.bat`，修改以下变量：
```batch
set FILE_DOMAIN=https://your-domain.com
set DB_USERNAME=your_db_user
set DB_PASSWORD=your_db_password
```

2. 运行：
```batch
start-prod.bat
```

#### Linux/Mac开发环境
```bash
chmod +x start-dev.sh
./start-dev.sh
```

#### Linux/Mac生产环境
1. 编辑 `start-prod.sh`，修改环境变量
2. 运行：
```bash
chmod +x start-prod.sh
./start-prod.sh
```

### 方法2：手动设置环境变量

#### Windows PowerShell
```powershell
# 开发环境
$env:FILE_UPLOAD_BASE_DIR="src/main/resources/static/images"
$env:FILE_DOMAIN="http://localhost:3000"
$env:DB_USERNAME="root"
$env:DB_PASSWORD="123456"
$env:JWT_SECRET="petshop_jwt_secret_key_2026"

# 启动后端
cd petserver
mvn spring-boot:run

# 新开一个终端启动前端
cd vue-pet
npm run serve
```

```powershell
# 生产环境
$env:FILE_UPLOAD_BASE_DIR="/var/www/petshop/images"
$env:FILE_DOMAIN="https://your-domain.com"
$env:DB_USERNAME="your_db_user"
$env:DB_PASSWORD="your_db_password"
$env:JWT_SECRET="your_jwt_secret"

# 启动
cd petserver
java -jar target/petserver-0.0.1-SNAPSHOT.jar
```

#### Windows CMD
```batch
# 开发环境
set FILE_UPLOAD_BASE_DIR=src/main/resources/static/images
set FILE_DOMAIN=http://localhost:3000
set DB_USERNAME=root
set DB_PASSWORD=123456
set JWT_SECRET=petshop_jwt_secret_key_2026

cd petserver
mvn spring-boot:run
```

#### Linux/Mac
```bash
# 开发环境
export FILE_UPLOAD_BASE_DIR="src/main/resources/static/images"
export FILE_DOMAIN="http://localhost:3000"
export DB_USERNAME="root"
export DB_PASSWORD="123456"
export JWT_SECRET="petshop_jwt_secret_key_2026"

cd petserver
mvn spring-boot:run
```

### 方法3：在IDE中配置（IDEA/Eclipse）

#### IntelliJ IDEA
1. 打开 `Run` -> `Edit Configurations`
2. 选择你的Spring Boot配置
3. 在 `Environment variables` 中添加：
```
FILE_UPLOAD_BASE_DIR=src/main/resources/static/images;
FILE_DOMAIN=http://localhost:3000;
DB_USERNAME=root;
DB_PASSWORD=123456;
JWT_SECRET=petshop_jwt_secret_key_2026
```

#### Eclipse
1. 右键项目 -> `Run As` -> `Run Configurations`
2. 选择 `Environment` 标签
3. 点击 `New` 添加环境变量

### 方法4：创建环境变量文件（需手动创建）

在 `petserver` 目录下创建文件：

#### `.env` (开发环境)
```properties
FILE_UPLOAD_BASE_DIR=src/main/resources/static/images
FILE_DOMAIN=http://localhost:3000
DB_USERNAME=root
DB_PASSWORD=123456
JWT_SECRET=petshop_jwt_secret_key_2026
```

#### `.env.prod` (生产环境)
```properties
FILE_UPLOAD_BASE_DIR=/var/www/petshop/images
FILE_DOMAIN=https://your-domain.com
DB_USERNAME=your_db_user
DB_PASSWORD=your_db_password
JWT_SECRET=your_jwt_secret
```

然后使用：
```bash
# Linux/Mac
source .env
mvn spring-boot:run

# Windows需要手动设置或使用脚本
```

## 🌍 环境变量说明

| 变量名 | 开发环境示例 | 生产环境示例 | 说明 |
|--------|-------------|-------------|------|
| `FILE_UPLOAD_BASE_DIR` | `src/main/resources/static/images` | `/var/www/petshop/images` | 文件上传根目录 |
| `FILE_DOMAIN` | `http://localhost:3000` | `https://your-domain.com` | 文件访问域名 |
| `DB_USERNAME` | `root` | `your_db_user` | 数据库用户名 |
| `DB_PASSWORD` | `123456` | `your_db_password` | 数据库密码 |
| `JWT_SECRET` | `petshop_jwt_secret_key_2026` | `your_jwt_secret` | JWT密钥 |

## 📝 验证配置是否生效

### 1. 启动后端，查看日志
应该看到类似输出：
```
文件上传配置:
  根目录: src/main/resources/static/images
  域名: http://localhost:3000
  URL前缀: /api/images
```

### 2. 上传一张图片
使用商家端或用户端上传图片，查看返回的URL：

开发环境返回：
```json
{
  "code": 200,
  "data": {
    "imageUrl": "http://localhost:3000/api/images/goods/goods_1_20260224120000_1234.jpg"
  }
}
```

生产环境返回：
```json
{
  "code": 200,
  "data": {
    "imageUrl": "https://your-domain.com/api/images/goods/goods_1_20260224120000_1234.jpg"
  }
}
```

### 3. 检查数据库
查看数据库中存储的URL是否为完整URL：
```sql
SELECT image_url FROM commodity LIMIT 1;
-- 应该返回: http://localhost:3000/api/images/goods/goods_1_20260224120000_1234.jpg
```

## 🔄 切换环境

### 从开发切换到生产

1. **修改环境变量**：
   - 将 `FILE_DOMAIN` 改为生产域名
   - 将 `FILE_UPLOAD_BASE_DIR` 改为生产路径
   - 修改数据库配置

2. **打包部署**：
```bash
cd petserver
mvn clean package
```

3. **启动生产环境**：
```bash
# 使用脚本
./start-prod.sh

# 或手动设置环境变量后启动
java -jar target/petserver-0.0.1-SNAPSHOT.jar
```

### 从生产切换回开发

1. 重新设置开发环境变量
2. 使用 `start-dev.bat` 或 `start-dev.sh` 启动

## ⚠️ 重要提示

1. **生产环境部署前必须修改**：
   - `FILE_DOMAIN` - 改为实际域名
   - `DB_PASSWORD` - 使用强密码
   - `JWT_SECRET` - 使用随机生成的强密钥

2. **确保目录权限**：
   - 生产环境的 `/var/www/petshop/images` 目录必须存在
   - 应用需要有写权限

3. **数据库迁移**：
   - 如果已有旧数据，需要更新图片URL
   - 可以编写SQL脚本批量更新

4. **前端配置**：
   - 前端直接使用后端返回的完整URL
   - 不需要额外配置图片域名

## 📞 问题排查

### 图片上传后无法访问
- 检查 `FILE_DOMAIN` 是否正确
- 检查文件是否真的保存到了指定目录
- 检查静态资源映射是否生效

### 数据库中URL不正确
- 检查 `FileUploadConfig` 是否正确注入
- 检查 `FileUploadUtil` 是否使用了配置类

### 环境变量不生效
- 确认环境变量已设置（使用 `echo %FILE_DOMAIN%` 或 `echo $FILE_DOMAIN` 检查）
- 重启IDE或终端
- 检查 `application.yml` 中的变量名是否正确
