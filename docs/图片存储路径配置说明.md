## 🔍 排查问题

### 问题1：404 Not Found

**检查：**
1. 文件是否存在：
```powershell
Get-ChildItem "c:\Users\rongyan\Desktop\ks\YellowPetShop\images\goods"
```

2. URL是否正确：
```
正确：http://localhost:3000/api/images/goods/goods_1_xxx.jpg
错误：http://localhost:3000/images/goods/goods_1_xxx.jpg
```

3. 路径映射是否生效（查看启动日志）

### 问题2：文件保存失败

**检查：**
1. 目录是否存在
2. 是否有写权限
3. 磁盘空间是否充足

### 问题3：旧图片无法访问

**原因：** 旧图片可能保存在其他位置

**解决：**
1. 重新上传图片
2. 或者将旧图片复制到新位置：
```powershell
Copy-Item "旧路径\*.jpg" "c:\Users\rongyan\Desktop\ks\YellowPetShop\images\goods\"
```

## 🌍 生产环境配置

### Linux服务器

```bash
# 创建目录
sudo mkdir -p /var/www/petshop/images/{goods,user/avatar,comment}
sudo chown -R tomcat:tomcat /var/www/petshop/images
sudo chmod -R 755 /var/www/petshop/images

# 设置环境变量
export FILE_UPLOAD_BASE_DIR="/var/www/petshop/images"
export FILE_URL_PREFIX="/api/images"

# 启动服务
java -jar petserver.jar
```

### Windows服务器

```batch
set FILE_UPLOAD_BASE_DIR=D:/www/petshop/images
set FILE_URL_PREFIX=/api/images

java -jar petserver.jar
```

## ⚠️ 注意事项

1. **路径分隔符** - Windows使用 `/` 或 `\` 都可以，建议使用 `/`
2. **绝对路径** - 使用绝对路径避免相对路径问题
3. **目录权限** - 确保应用有读写权限
4. **备份** - 定期备份图片目录
5. **清理** - 定期清理无用的图片文件

## 🎯 优势

✅ **独立存储** - 图片与代码分离，便于管理  
✅ **易于备份** - 单独备份图片目录  
✅ **便于迁移** - 可以轻松迁移到其他位置或CDN  
✅ **不影响打包** - 图片不会被打包到jar中  
✅ **统一管理** - 所有图片集中在一个位置
