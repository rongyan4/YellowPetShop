# 会员管理详情页功能说明

## 功能概述

会员管理详情页提供了完整的会员信息查看和管理功能，包括基本信息、钱包管理、地址管理和订单查看。

## 前端实现

### 页面路径
- 文件位置：`vue-pet/src/views/merchant/MemberDetail.vue`
- 访问路径：`/merchant/members/:id`

### 主要功能模块

#### 1. 基本信息管理
- **显示内容**：
  - 用户头像
  - 用户名、昵称
  - 邮箱、手机号
  - 性别、生日
  - 注册时间、账户状态

- **编辑功能**：
  - 点击"编辑"按钮打开对话框
  - 可修改：昵称、邮箱、手机号、性别、生日
  - 保存后自动刷新数据

#### 2. 钱包信息管理
- **显示内容**：
  - 账户余额（带渐变色显示）
  - 支付密码状态（已设置/未设置）

- **管理功能**：
  - **调整余额**：输入正数增加余额，负数减少余额，需填写备注
  - **重置支付密码**：设置新的6位数字支付密码

#### 3. 收货地址管理
- **显示内容**：
  - 收货人姓名和电话
  - 完整地址（省市区+详细地址）
  - 默认地址标识

- **管理功能**：
  - **添加地址**：填写完整的收货地址信息
  - **编辑地址**：修改现有地址信息
  - **删除地址**：删除不需要的地址（需确认）
  - **设为默认**：通过编辑对话框设置默认地址

#### 4. 订单统计
- 总订单数
- 总消费金额
- 待付款订单数
- 已完成订单数

#### 5. 最近订单列表
- 显示最近10条订单
- 包含订单号、商品、金额、状态、创建时间
- 可点击"查看"按钮跳转到订单详情页

## 后端实现

### API接口

#### 1. 会员详情接口
```
GET /api/user/{userId}
```
返回用户的完整信息，包括基本信息和钱包余额。

#### 2. 更新会员信息
```
POST /api/user/update_info
Body: {
  userId: Long,
  nickname: String,
  email: String,
  phone: String,
  gender: String,
  birthday: String
}
```

#### 3. 调整会员余额
```
POST /api/merchant/members/{userId}/balance
Body: {
  amount: Number,  // 正数增加，负数减少
  remark: String   // 调整原因
}
```

#### 4. 重置支付密码
```
POST /api/merchant/members/{userId}/reset-pay-password
Body: {
  newPassword: String  // 6位数字
}
```

#### 5. 地址管理接口
```
GET /api/address/list?userId={userId}           // 获取地址列表
POST /api/address/add                            // 添加地址
PUT /api/address/update/{addressId}              // 更新地址
DELETE /api/address/delete/{addressId}           // 删除地址
```

#### 6. 会员订单列表
```
GET /api/merchant/orders?userId={userId}&page=1&pageSize=10
```

### 数据库表

#### user 表
存储用户基本信息：
- id, username, password, email, nickname
- gender, avatar, status, role, birthday, phone
- points, is_valid, create_time, update_time

#### user_wallet 表
存储用户钱包信息：
- id, user_id, balance, pay_password
- is_locked, lock_time, error_count
- create_time, update_time

#### user_address 表
存储用户地址信息：
- id, user_id, receiver_name, receiver_phone
- province, city, district, detail_address
- is_default, create_time, update_time

## 使用说明

### 商家端操作流程

1. **查看会员详情**
   - 在会员管理列表中点击某个会员
   - 进入会员详情页查看完整信息

2. **编辑会员信息**
   - 点击基本信息卡片的"编辑"按钮
   - 修改需要更新的字段
   - 点击"保存"提交更改

3. **调整会员余额**
   - 点击钱包信息卡片的"调整余额"按钮
   - 输入调整金额（正数增加，负数减少）
   - 填写调整原因备注
   - 点击"确定"完成调整

4. **重置支付密码**
   - 点击支付密码旁的"重置"按钮
   - 输入新的6位数字密码
   - 确认密码
   - 点击"确定"完成重置

5. **管理收货地址**
   - 点击"添加地址"按钮添加新地址
   - 点击地址卡片的"编辑"按钮修改地址
   - 点击"删除"按钮删除地址（需确认）
   - 在编辑对话框中勾选"设为默认地址"

6. **查看订单信息**
   - 查看订单统计数据
   - 浏览最近订单列表
   - 点击"查看"按钮查看订单详情

## 注意事项

1. **权限控制**
   - 所有接口需要商家登录认证
   - 通过JWT Token验证身份

2. **数据验证**
   - 邮箱格式验证
   - 手机号格式验证
   - 支付密码必须是6位数字
   - 地址信息必须完整填写

3. **余额调整**
   - 减少余额时会检查余额是否充足
   - 所有余额变动都会记录操作日志

4. **地址管理**
   - 设置新的默认地址时会自动取消其他默认地址
   - 删除地址需要确认操作

5. **性能优化**
   - 订单列表默认只显示最近10条
   - 使用分页加载大量数据
