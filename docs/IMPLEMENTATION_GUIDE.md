# 商品分类系统实现说明

## 已完成的功能

### 1. 订单详情页倒计时 ✅
- 在订单详情页面显示待支付订单的剩余支付时间
- 倒计时为5分钟，每秒更新一次
- 超时后自动刷新订单状态

### 2. 商品分类系统 ✅

#### 数据库层面
- 创建了 `category` 表，包含以下字段：
  - id: 分类ID
  - name: 分类名称
  - icon: 分类图标
  - sort_order: 排序顺序
  - create_time: 创建时间
  - update_time: 更新时间

- 插入了6个分类数据：
  1. 狗粮
  2. 猫粮
  3. 零食
  4. 玩具
  5. 用品
  6. 保健品

- 修改了 `commodity` 表，添加了 `category_id` 字段
- 为所有现有商品随机分配了分类

#### 后端层面
创建的文件：
1. `Category.java` - 分类实体类
2. `CategoryMapper.java` - 分类数据访问层
3. `CategoryService.java` - 分类服务接口
4. `CategoryServiceImpl.java` - 分类服务实现
5. `CategoryController.java` - 分类控制器

修改的文件：
1. `CommodityInfo.java` - 添加了 categoryId 字段
2. `CommodityMapper.java` - 添加了按分类查询的方法

新增API接口：
- `GET /api/category/all` - 获取所有分类列表
- `GET /api/category/preview` - 获取分类及商品预览
- `GET /api/category/goods?categoryId=1&current=1&size=10` - 按分类分页获取商品

#### 前端层面
修改的文件：
1. `goods.js` - 添加了分类相关的API方法
2. `List.vue` - 完全重写，实现了新的分类展示逻辑

功能特性：
- **分类预览模式**：
  - 左侧显示所有分类导航（带图标）
  - 右侧显示每个分类的商品预览
  - 每个分类显示3×2（6个）商品格子
  - 第6个格子显示"+"号，点击可查看更多

- **分类详情模式**：
  - 点击"查看更多"进入该分类的详情页
  - 使用两列瀑布流布局展示所有商品
  - 支持下拉加载更多
  - 可以返回预览模式

## 部署步骤

### 1. 执行数据库脚本
```bash
# 在MySQL中执行以下SQL文件
mysql -u root -p petshop < category_update.sql
```

或者手动执行 `category_update.sql` 文件中的SQL语句。

### 2. 重启后端服务
```bash
cd petserver
mvn clean package
java -jar target/petserver.jar
```

### 3. 前端无需额外操作
前端代码已更新，刷新页面即可看到新功能。

## 测试建议

1. **测试订单详情页倒计时**：
   - 创建一个新订单
   - 进入订单详情页
   - 观察倒计时是否正常显示和更新

2. **测试分类预览**：
   - 进入"分类"标签页
   - 查看左侧分类导航是否正常显示
   - 查看右侧每个分类的商品预览
   - 点击左侧分类，右侧应滚动到对应位置

3. **测试分类详情**：
   - 点击任意分类的"查看更多"（+号）
   - 进入该分类的详情页
   - 查看瀑布流布局是否正常
   - 测试下拉加载更多功能
   - 点击返回按钮，应回到预览模式

4. **测试商品跳转**：
   - 在预览模式点击商品，应跳转到商品详情页
   - 在详情模式点击商品，应跳转到商品详情页

## 注意事项

1. 确保数据库中已有商品数据
2. 确保后端服务正常运行
3. 如果分类图标显示异常，可以在数据库中修改 `category` 表的 `icon` 字段
4. 商品图片路径需要正确配置
