# 购物车问题排查指南

## 问题：购物车显示有商品，但 cart_item 表是空的

### 可能原因

1. **前端显示的是缓存数据**
2. **用户未登录或 Token 失效**
3. **后端接口未正常工作**
4. **数据库连接问题**

---

## 排查步骤

### 1. 检查用户登录状态

打开浏览器控制台（F12），执行：

```javascript
// 检查 token
console.log('Token:', localStorage.getItem('token'));

// 检查用户信息
console.log('UserInfo:', localStorage.getItem('userInfo'));
```

**如果没有 token**：
- 需要先登录
- 登录后再添加商品到购物车

---

### 2. 清除浏览器缓存

**方法1：强制刷新**
- Windows: `Ctrl + Shift + R`
- Mac: `Cmd + Shift + R`

**方法2：清除所有缓存**
1. 打开浏览器控制台（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

**方法3：清除 localStorage**
```javascript
// 在控制台执行
localStorage.clear();
location.reload();
```

---

### 3. 测试添加购物车功能

#### 步骤：
1. **登录账号**
   - 访问 http://localhost:80
   - 点击"我的"进行登录

2. **添加商品到购物车**
   - 进入商品详情页
   - 点击"加入购物车"按钮
   - 查看是否提示"已加入购物车"

3. **查看购物车**
   - 点击"购物车"标签
   - 查看是否显示刚添加的商品

4. **检查数据库**
```sql
-- 查看购物车表数据
SELECT * FROM cart_item;

-- 查看特定用户的购物车
SELECT ci.*, c.name, c.price 
FROM cart_item ci
LEFT JOIN commodity c ON ci.commodity_id = c.id
WHERE ci.user_id = 1;  -- 替换为你的用户ID
```

---

### 4. 检查后端日志

查看后端控制台输出，看是否有错误信息：

```bash
# 如果使用 Spring Boot
# 查看日志文件
tail -f petserver/app.log

# 或查看控制台输出
```

常见错误：
- `401 Unauthorized` - Token 失效或未登录
- `500 Internal Server Error` - 后端代码错误
- `404 Not Found` - 接口路径错误

---

### 5. 测试后端接口

使用 Postman 或 curl 测试接口：

#### 5.1 登录获取 Token
```bash
curl -X POST http://localhost:8080/api/user/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "your_username",
    "password": "your_password"
  }'
```

#### 5.2 添加商品到购物车
```bash
curl -X POST "http://localhost:8080/api/cart/add?commodityId=1&quantity=1" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

#### 5.3 查看购物车列表
```bash
curl -X GET http://localhost:8080/api/cart/list \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

---

### 6. 检查数据库表结构

确保 `cart_item` 表存在且结构正确：

```sql
-- 查看表结构
DESC cart_item;

-- 应该包含以下字段：
-- id, user_id, commodity_id, quantity, checked, create_time, update_time
```

如果表不存在或结构不对，重新执行：
```bash
mysql -u root -p petshop < petshop.sql
```

---

### 7. 检查前端 API 配置

查看 `vue-pet/src/utils/request.js` 中的 baseURL 配置：

```javascript
const service = axios.create({
  baseURL: '/api/',  // 应该是 '/api/'
  timeout: 10000
});
```

查看 `vue-pet/vue.config.js` 中的代理配置：

```javascript
devServer: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',  // 后端地址
      changeOrigin: true
    }
  }
}
```

---

## 快速修复方案

### 方案1：重新登录并添加商品

1. 退出登录（如果已登录）
2. 清除浏览器缓存
3. 重新登录
4. 添加商品到购物车
5. 检查数据库

### 方案2：直接在数据库插入测试数据

```sql
-- 插入测试购物车数据
INSERT INTO cart_item (user_id, commodity_id, quantity, checked) 
VALUES (1, 1, 2, 1);

-- 查看结果
SELECT * FROM cart_item;
```

然后刷新前端页面，看是否显示。

## 常见问题

### Q1: 添加购物车后提示"未登录"
**A**: Token 失效或未登录，需要重新登录。

### Q2: 添加购物车成功，但购物车页面是空的
**A**: 
1. 检查是否使用同一个账号
2. 刷新页面
3. 查看浏览器控制台是否有错误

### Q3: 后端返回 500 错误
**A**: 
1. 检查后端日志
2. 确认数据库连接正常
3. 确认商品 ID 存在且有效

### Q4: 前端显示商品但数据库是空的
**A**: 
1. 这是缓存问题，清除浏览器缓存
2. 使用隐私模式/无痕模式测试
3. 检查是否在看不同的数据库

## 调试技巧

### 在浏览器控制台查看网络请求

1. 打开控制台（F12）
2. 切换到 Network 标签
3. 点击"加入购物车"按钮
4. 查看请求：
   - 请求 URL: `/api/cart/add?commodityId=xxx&quantity=1`
   - 请求方法: POST
   - 请求头: 包含 `Authorization: Bearer xxx`
   - 响应状态: 200 表示成功
   - 响应数据: `{"code": 200, "msg": "添加成功"}`

### 查看购物车加载请求

1. 进入购物车页面
2. 查看 Network 标签
3. 找到 `/api/cart/list` 请求
4. 查看响应数据是否包含商品
