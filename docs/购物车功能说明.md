# 购物车功能说明

## 功能概述

已成功集成购物车后端接口，用户可以在商品详情页添加商品到购物车，并在购物车页面管理商品。

## 数据库结构

购物车使用 `cart_item` 表存储数据：

```sql
CREATE TABLE `cart_item` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '购物车项ID',
  `user_id` bigint NOT NULL COMMENT '用户ID',
  `commodity_id` bigint NOT NULL COMMENT '商品ID',
  `quantity` int NOT NULL DEFAULT 1 COMMENT '商品数量',
  `checked` tinyint(1) NULL DEFAULT 1 COMMENT '是否选中 1-选中 0-未选中',
  `create_time` datetime NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE INDEX `uk_user_commodity`(`user_id`, `commodity_id`) -- 同一用户同一商品只能有一条记录
);
```

## 后端接口

### 1. 添加商品到购物车
- **接口**: `POST /api/cart/add`
- **参数**: 
  - `commodityId`: 商品ID (必填)
  - `quantity`: 数量 (可选，默认1)
- **需要登录**: 是
- **说明**: 如果商品已存在，会累加数量

### 2. 获取购物车列表
- **接口**: `GET /api/cart/list`
- **需要登录**: 是
- **返回**: 购物车商品列表（包含商品详细信息）

### 3. 更新商品数量
- **接口**: `PUT /api/cart/quantity`
- **参数**:
  - `cartItemId`: 购物车项ID
  - `quantity`: 新数量

### 4. 更新选中状态
- **接口**: `PUT /api/cart/checked`
- **参数**:
  - `cartItemId`: 购物车项ID
  - `checked`: 是否选中 (true/false)

### 5. 删除购物车商品
- **接口**: `DELETE /api/cart/delete`
- **参数**:
  - `cartItemId`: 购物车项ID

### 6. 清空购物车
- **接口**: `DELETE /api/cart/clear`
- **需要登录**: 是

## 前端实现

### 商品详情页 (GoodDetailsView.vue)

点击"加入购物车"按钮时：
1. 检查用户是否登录
2. 如果未登录，弹出登录提示
3. 如果已登录，调用 `addToCartSafe` 接口添加商品
4. 显示成功提示

```javascript
const addToCart = async () => {
  const token = localStorage.getItem('token');
  if (!token) {
    // 提示登录
    showDialog({
      title: '提示',
      message: '请先登录',
      confirmButtonText: '去登录',
    }).then(() => {
      router.push('/my');
    });
    return;
  }
  
  // 调用接口
  const result = await addToCartSafe(goodsInfo.value.id, 1);
  if (result !== null) {
    showToast({ message: '已加入购物车', icon: 'success' });
  }
};
```

### 购物车页面 (CarView.vue)

功能包括：
1. **显示购物车商品列表** - 从后端加载数据
2. **增减数量** - 调用更新数量接口
3. **选中/取消选中** - 调用更新选中状态接口
4. **删除商品** - 编辑模式下删除选中商品
5. **全选/取消全选** - 批量更新选中状态
6. **计算总价** - 根据选中商品计算

## API 调用示例

### 前端 API 封装 (cart.js)

```javascript
// 添加到购物车
export const addToCart = (commodityId, quantity = 1) => {
  return post(`/cart/add?commodityId=${commodityId}&quantity=${quantity}`);
};

// 获取购物车列表
export const getCartList = () => {
  return get('/cart/list');
};

// 更新数量
export const updateCartQuantity = (cartItemId, quantity) => {
  return put(`/cart/quantity?cartItemId=${cartItemId}&quantity=${quantity}`);
};

// 更新选中状态
export const updateCartChecked = (cartItemId, checked) => {
  return put(`/cart/checked?cartItemId=${cartItemId}&checked=${checked}`);
};

// 删除商品
export const deleteCartItem = (cartItemId) => {
  return del(`/cart/delete?cartItemId=${cartItemId}`);
};
```

## 使用流程

1. **用户登录** - 必须先登录才能使用购物车功能
2. **浏览商品** - 在商品详情页查看商品信息
3. **添加到购物车** - 点击"加入购物车"按钮
4. **查看购物车** - 进入购物车页面查看已添加的商品
5. **管理商品** - 修改数量、选中状态或删除商品
6. **结算** - 选中商品后进行结算（功能待开发）

## 注意事项

1. **登录验证**: 所有购物车接口都需要 JWT Token 验证
2. **唯一性约束**: 同一用户同一商品只能有一条购物车记录，重复添加会累加数量
3. **数据同步**: 前端操作后会立即同步到后端数据库
4. **错误处理**: 接口调用失败时会显示错误提示并恢复原状态
