# 会员管理功能完善说明文档

## 功能概述

本次更新完善了商家端的会员管理功能，新增了会员详情页面，可以查看和管理用户的详细信息。

## 一、新增功能

### 1. 会员列表页面增强

**文件**: `vue-pet/src/views/merchant/MemberManagement.vue`

**新增功能**:
- ✅ 添加"详情"按钮
- ✅ 点击详情按钮跳转到会员详情页

**修改内容**:
```vue
<button @click="handleViewDetail(item)" class="btn-detail">详情</button>
```

### 2. 会员详情页面

**文件**: `vue-pet/src/views/merchant/MemberDetail.vue`

**功能模块**:

#### 2.1 基本信息卡片
- 显示用户ID、用户名、昵称、邮箱、手机号、性别、生日、注册时间、账户状态
- 支持编辑基本信息（昵称、邮箱、手机号、性别、生日）

#### 2.2 钱包信息卡片
- 显示账户余额
- 显示支付密码状态（已设置/未设置）
- 支持调整余额（增加或减少）
- 支持重置支付密码

#### 2.3 订单统计卡片
- 总订单数
- 总消费金额
- 待付款订单数
- 已完成订单数

#### 2.4 订单列表
- 显示该用户的所有订单
- 订单号、商品信息、金额、状态、创建时间
- 支持查看订单详情

## 二、API接口

### 1. 前端API

**文件**: `vue-pet/src/api/merchant.js`

```javascript
// 获取会员详情
export function getMemberDetail(userId)

// 更新会员信息
export function updateMemberInfo(userId, data)

// 调整会员余额
export function adjustMemberBalance(userId, data)

// 重置会员支付密码
export function resetMemberPayPassword(userId, data)

// 获取会员订单列表
export function getMemberOrders(userId, params)
```

### 2. 后端API

**Controller**: `MerchantMemberController.java`

| 接口 | 方法 | 路径 | 说明 |
|-----|------|------|------|
| 获取会员详情 | GET | `/api/merchant/members/{userId}` | 返回用户信息、钱包信息、订单统计 |
| 更新会员信息 | PUT | `/api/merchant/members/{userId}` | 更新昵称、邮箱、手机号等 |
| 调整会员余额 | POST | `/api/merchant/members/{userId}/balance` | 增加或减少余额 |
| 重置支付密码 | POST | `/api/merchant/members/{userId}/pay-password` | 重置6位数字支付密码 |
| 获取会员订单 | GET | `/api/merchant/members/{userId}/orders` | 分页查询用户订单 |

**Service**: `MerchantMemberService.java` 和 `MerchantMemberServiceImpl.java`

## 四、功能详解

### 1. 编辑基本信息

**操作流程**:
1. 点击"编辑"按钮
2. 弹出编辑对话框
3. 修改昵称、邮箱、手机号、性别、生日
4. 点击"保存"提交

**后端处理**:
- 验证用户是否存在
- 更新用户信息到数据库
- 返回成功/失败消息

### 2. 调整余额

**操作流程**:
1. 点击钱包信息的"管理"按钮
2. 弹出钱包管理对话框
3. 输入调整金额（正数增加，负数减少）
4. 输入备注说明
5. 点击"确定"提交

**后端处理**:
- 获取或创建用户钱包
- 计算新余额
- 验证余额是否充足（扣减时）
- 更新钱包余额
- 记录操作日志

**示例**:
```javascript
// 增加100元
{ amount: 100, remark: "充值奖励" }

// 减少50元
{ amount: -50, remark: "退款" }
```

### 3. 重置支付密码

**操作流程**:
1. 点击"重置"按钮
2. 弹出重置密码对话框
3. 输入新的6位数字密码
4. 确认密码
5. 点击"确定"提交

**后端处理**:
- 验证密码格式（必须6位数字）
- 验证两次密码是否一致
- 使用BCrypt加密密码
- 更新钱包支付密码

### 4. 查看订单列表

**显示内容**:
- 订单号
- 商品信息（显示第一个商品，如有多个显示"等N件商品"）
- 订单金额
- 订单状态（待付款/已付款/已发货/已完成/已取消）
- 创建时间
- 操作按钮（查看详情）

**点击查看**:
- 跳转到订单详情页面
- 路径: `/merchant/orders/{orderId}`

## 九、注意事项

### 1. 数据安全
- 支付密码使用BCrypt加密
- 敏感操作记录日志
- 余额调整需要备注说明

### 2. 操作审计
- 记录商家ID
- 记录操作时间
- 记录操作内容

### 3. 用户体验
- 加载状态提示
- 操作成功/失败提示
- 表单验证提示
