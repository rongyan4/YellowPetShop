# 订单系统功能说明

## 功能概述

已完成订单系统的前后端实现，支持购物车结算和立即购买两种下单方式。

## 数据库变更

### 1. 执行数据库脚本

请先执行 `order_system.sql` 脚本来创建订单相关表：

```bash
mysql -u root -p petshop < order_system.sql
```

### 2. 新增表结构

#### orders 表（订单主表）
```sql
CREATE TABLE `orders` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '订单ID',
  `order_sn` varchar(64) NOT NULL COMMENT '订单编号',
  `user_id` bigint NOT NULL COMMENT '用户ID',
  `total_amount` decimal(10, 2) NOT NULL COMMENT '订单总金额',
  `postage` decimal(10, 2) NOT NULL DEFAULT 0.00 COMMENT '邮费',
  `pay_amount` decimal(10, 2) NOT NULL COMMENT '实付金额',
  `status` varchar(20) NOT NULL DEFAULT 'PENDING' COMMENT '订单状态',
  `receiver_name` varchar(100) NULL COMMENT '收货人姓名',
  `receiver_phone` varchar(20) NULL COMMENT '收货人电话',
  `receiver_address` varchar(500) NULL COMMENT '收货地址',
  `remark` varchar(500) NULL COMMENT '订单备注',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `pay_time` datetime NULL COMMENT '支付时间',
  `ship_time` datetime NULL COMMENT '发货时间',
  `complete_time` datetime NULL COMMENT '完成时间',
  PRIMARY KEY (`id`),
  UNIQUE INDEX `uk_order_sn`(`order_sn`)
);
```

#### order_item 表（订单商品明细表）
```sql
CREATE TABLE `order_item` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '订单商品ID',
  `order_id` bigint NOT NULL COMMENT '订单ID',
  `commodity_id` bigint NOT NULL COMMENT '商品ID',
  `commodity_name` varchar(255) NOT NULL COMMENT '商品名称',
  `commodity_pic` varchar(500) NULL COMMENT '商品图片',
  `commodity_price` decimal(10, 2) NOT NULL COMMENT '商品单价',
  `quantity` int NOT NULL COMMENT '购买数量',
  `total_price` decimal(10, 2) NOT NULL COMMENT '小计金额',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
);
```

### 3. 订单状态说明

- `PENDING` - 待付款
- `PAID` - 已付款
- `SHIPPED` - 已发货
- `COMPLETED` - 已完成
- `CANCELLED` - 已取消

## 后端接口

### 1. 创建订单
- **接口**: `POST /api/order/create`
- **需要登录**: 是
- **请求体**:
```json
{
  "cartItemIds": [1, 2, 3],  // 购物车商品ID列表（购物车结算时使用）
  "commodityId": 1,           // 商品ID（立即购买时使用）
  "quantity": 1,              // 购买数量（立即购买时使用）
  "receiverName": "张三",
  "receiverPhone": "13800138000",
  "receiverAddress": "北京市朝阳区xxx",
  "remark": "请尽快发货"
}
```
- **返回**: 订单详情（包含订单商品列表）

### 2. 获取订单列表
- **接口**: `GET /api/order/list`
- **需要登录**: 是
- **返回**: 用户所有订单列表

### 3. 获取订单详情
- **接口**: `GET /api/order/detail/{orderId}`
- **需要登录**: 是
- **返回**: 订单详情

### 4. 取消订单
- **接口**: `PUT /api/order/cancel/{orderId}`
- **需要登录**: 是
- **限制**: 只能取消待付款状态的订单

### 5. 删除订单
- **接口**: `DELETE /api/order/delete/{orderId}`
- **需要登录**: 是
- **限制**: 只能删除已取消或已完成的订单

## 前端实现

### 1. 购物车结算（CarView.vue）

点击"结算"按钮时：
1. 检查是否有选中商品
2. 弹出确认对话框显示订单信息
3. 调用创建订单接口
4. 成功后刷新购物车列表（已购买商品会被自动删除）

```javascript
const handleCheckout = async () => {
  const selectedItems = cartItems.value.filter(item => item.selected);
  
  showDialog({
    title: '确认下单',
    message: `共 ${selectedCount.value} 件商品，合计 ¥${totalPrice.value}`,
  }).then(async () => {
    const orderData = {
      cartItemIds: selectedItems.map(item => item.id),
      receiverName: '默认收货人',
      receiverPhone: '13800138000',
      receiverAddress: '默认收货地址',
      remark: ''
    };
    
    const result = await createOrderSafe(orderData);
    if (result) {
      showToast('下单成功');
      await loadCartData();
    }
  });
};
```

## 业务流程

### 购物车结算流程
1. 用户在购物车选中商品
2. 点击"结算"按钮
3. 确认订单信息
4. 创建订单（状态：待付款）
5. 自动删除购物车中已下单的商品
6. 显示下单成功提示

### 立即购买流程
1. 用户在商品详情页点击"立即购买"
2. 确认购买信息
3. 创建订单（状态：待付款）
4. 显示下单成功提示

### 订单管理流程
1. 用户查看订单列表
2. 可以取消待付款订单
3. 可以删除已完成/已取消订单
4. 可以支付待付款订单（待开发）

## 注意事项

### 1. 空值处理
修复了 `commodity.getIsValid()` 可能返回 `null` 的问题：

```java
if (commodity == null) {
    throw new RuntimeException("商品不存在");
}
if (commodity.getIsValid() != null && !commodity.getIsValid()) {
    throw new RuntimeException("商品已下架");
}
```

### 2. 订单号生成规则
格式：`yyyyMMddHHmmss` + 用户ID后4位 + 4位随机数

例如：`20260214103012000112345`

### 3. 事务处理
创建订单、取消订单、删除订单都使用了 `@Transactional` 注解确保数据一致性。

### 4. 权限验证
所有订单操作都会验证：
- 用户是否登录（JWT Token）
- 用户是否有权限操作该订单

### 5. 收货地址
当前使用默认收货地址，后续可以：
- 集成地址管理功能
- 在下单时选择收货地址
- 支持新增/编辑收货地址
