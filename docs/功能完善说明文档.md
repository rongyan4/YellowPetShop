## 📦 数据库变更

### 1. 执行升级脚本
```bash
# 在MySQL中执行
source database_upgrade.sql
```

### 2. 主要变更内容

#### 2.1 修改 `commodity` 表
- `postage` - 邮费字段，精度 DECIMAL(10,2)，默认 0.00
- `is_valid` - 是否有效，默认 1
- `shipping_origin` - 发货地，默认"上海"
- `detail` - 商品详情（支持富文本HTML）

#### 2.2 新增 `commodity_image` 表
存储商品多图，支持轮播展示
```sql
- id: 图片ID
- commodity_id: 商品ID
- image_url: 图片URL
- sort_order: 排序顺序
- is_main: 是否主图
```

#### 2.3 重新设计 `cart_item` 表
直接关联商品和用户，不再依赖 `commodity_item`
```sql
- id: 购物车项ID
- user_id: 用户ID
- commodity_id: 商品ID
- quantity: 商品数量
- checked: 是否选中
```

#### 2.4 新增 `comment_image` 表
存储评论图片
```sql
- id: 评论图片ID
- comment_id: 评论ID
- image_url: 图片URL
- sort_order: 排序顺序
```

#### 2.5 优化 `comment` 表
- `order_id` - 改为可空（允许未购买用户评论）
- `parent_id` - 改为可空（用于回复评论）
- 添加默认值和注释

### 3. 回滚方案
如果需要撤销更新：
```bash
# 在MySQL中执行
source database_rollback.sql
```

⚠️ **警告**：回滚将删除所有升级后添加的数据！

### 2. 更新页面

#### GoodDetailsView.vue（商品详情页）
**新增功能：**
- ✅ 显示发货地和邮费信息
- ✅ 支持多图轮播（从后端加载）
- ✅ 显示商品详情HTML（支持富文本）
- ✅ 从后端加载评论列表
- ✅ 显示评论图片
- ✅ 显示评论总数

**数据流：**
```
页面加载 → 获取商品ID → 调用 getGoodDetailSafe(id)
         ↓
    更新商品信息（价格、名称、发货地、邮费、详情）
         ↓
    更新商品图片列表（轮播图）
         ↓
    加载评论列表 → getCommentsByPageSafe(id, 1, 10)
         ↓
    加载评论总数 → getCommentCountSafe(id)
```

#### CarView.vue（购物车页）
**新增功能：**
- ✅ 从后端加载购物车数据
- ✅ 更新商品数量（同步到后端）
- ✅ 更新选中状态（同步到后端）
- ✅ 删除购物车项（同步到后端）
- ✅ 全选/取消全选（批量更新）
- ✅ 登录状态监听（自动加载数据）

**数据流：**
```
页面加载 → 检查登录状态 → 已登录？
                          ↓ 是
                    调用 getCartListSafe()
                          ↓
                    转换数据格式并显示
                          ↓
    用户操作（增减数量、选中、删除）
                          ↓
                    调用对应API更新后端
                          ↓
                    更新成功 → 更新本地状态
                    更新失败 → 恢复原状态 + 提示
```

## ⚠️ 注意事项

### 1. 数据库
- 执行升级脚本前请备份数据库
- 确保 MySQL 版本支持 JSON 和富文本字段
- 外键约束已设置级联删除

### 2. 后端
- 需要 Spring Boot 2.x+
- 需要 MyBatis-Plus 3.x+
- JWT token 用于用户认证

### 3. 前端
- 需要 Vue 3
- 需要 Vant 4
- 需要配置 axios 拦截器（自动添加 token）

### 4. 安全性
- 购物车操作需要登录
- Token 验证在拦截器中处理
- 评论查看无需登录，发表评论需要登录（待实现）
