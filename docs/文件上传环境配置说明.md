# 文件上传配置说明

## 📋 配置概述

本项目已实现文件上传的完整配置方案，包括：
- 后端使用宏定义管理上传根目录
- 数据库存储完整的图片URL
- 支持开发环境和生产环境区分
- 前端直接使用完整URL

## 🔧 后端配置

### 1. 环境变量配置

在项目根目录创建环境变量文件（根据环境选择）：

#### 开发环境 `.env` 或 `.env.dev`
```properties
# 数据库配置
DB_URL=jdbc:mysql://localhost:3306/pet_shop?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useUnicode=true&characterEncoding=utf-8
DB_USERNAME=root
DB_PASSWORD=123456

# JWT密钥
JWT_SECRET=petshop_jwt_secret_key_2026

# 文件上传配置 - 开发环境
FILE_UPLOAD_BASE_DIR=src/main/resources/static/images
FILE_DOMAIN=http://localhost:3000
```

#### 生产环境 `.env.prod`
```properties
# 数据库配置
DB_URL=jdbc:mysql://your-production-db-host:3306/pet_shop?useSSL=true&serverTimezone=Asia/Shanghai
DB_USERNAME=your_production_db_user
DB_PASSWORD=your_production_db_password

# JWT密钥
JWT_SECRET=your_production_jwt_secret_key

# 文件上传配置 - 生产环境
FILE_UPLOAD_BASE_DIR=/var/www/petshop/images
FILE_DOMAIN=https://your-domain.com
```

### 2. application.yml 配置

已在 `application.yml` 中添加文件上传配置：

```yaml
file:
  upload:
    base-dir: ${FILE_UPLOAD_BASE_DIR:src/main/resources/static/images}
    domain: ${FILE_DOMAIN:http://localhost:3000}
    url-prefix: /api/images
```

### 3. 配置类

已创建 `FileUploadConfig.java` 配置类，用于：
- 读取环境变量配置
- 配置静态资源映射
- 提供完整URL生成方法

### 4. 工具类

已更新 `FileUploadUtil.java`，现在会：
- 使用配置的根目录保存文件
- 返回完整的图片URL（包含域名）
- 支持不同环境的URL生成

## 🌐 前端配置

### 1. 环境变量配置

在 `vue-pet` 目录创建环境变量文件：

#### 开发环境 `.env.development`
```properties
# API基础路径
VUE_APP_API_BASE_URL=http://localhost:3000/api

# 图片域名（可选，如果后端返回完整URL则不需要）
VUE_APP_IMAGE_DOMAIN=http://localhost:3000
```

#### 生产环境 `.env.production`
```properties
# API基础路径
VUE_APP_API_BASE_URL=https://your-domain.com/api

# 图片域名（可选）
VUE_APP_IMAGE_DOMAIN=https://your-domain.com
```

### 2. 前端使用方式

由于后端已返回完整URL，前端可以直接使用：

```javascript
// 商品图片
<img :src="product.imageUrl" />

// 用户头像
<img :src="userInfo.avatarUrl" />

// 评论图片
<img :src="comment.imageUrl" />
```

## 🚀 启动方式

### 开发环境

#### Windows
```batch
# 设置环境变量（PowerShell）
$env:FILE_UPLOAD_BASE_DIR="src/main/resources/static/images"
$env:FILE_DOMAIN="http://localhost:3000"
$env:DB_USERNAME="root"
$env:DB_PASSWORD="123456"
$env:JWT_SECRET="petshop_jwt_secret_key_2026"

# 启动后端
cd petserver
mvn spring-boot:run
```

#### Linux/Mac
```bash
# 设置环境变量
export FILE_UPLOAD_BASE_DIR="src/main/resources/static/images"
export FILE_DOMAIN="http://localhost:3000"
export DB_USERNAME="root"
export DB_PASSWORD="123456"
export JWT_SECRET="petshop_jwt_secret_key_2026"

# 启动后端
cd petserver
mvn spring-boot:run
```

### 生产环境

#### 使用环境变量文件
```bash
# 加载生产环境变量
source .env.prod

# 或者在启动脚本中设置
export FILE_UPLOAD_BASE_DIR="/var/www/petshop/images"
export FILE_DOMAIN="https://your-domain.com"

# 打包并运行
mvn clean package
java -jar target/petserver-0.0.1-SNAPSHOT.jar
```

#### 使用系统环境变量
在服务器上配置系统环境变量，然后直接启动应用。

## 📝 数据库说明

数据库中存储的是完整的图片URL，例如：

```sql
-- 用户表
UPDATE user SET avatar_url = 'http://localhost:3000/api/images/user/avatar/user_1_20260224120000_1234.jpg';

-- 商品表
UPDATE commodity SET image_url = 'http://localhost:3000/api/images/goods/goods_1_20260224120000_5678.jpg';

-- 评论表
UPDATE comment SET image_url = 'http://localhost:3000/api/images/comment/comment_1_20260224120000_9012.jpg';
```

生产环境会自动使用生产域名：
```
https://your-domain.com/api/images/user/avatar/user_1_20260224120000_1234.jpg
```

## 🔄 环境切换

### 方法1：使用不同的环境变量文件

```bash
# 开发环境
source .env.dev
mvn spring-boot:run

# 生产环境
source .env.prod
java -jar target/petserver-0.0.1-SNAPSHOT.jar
```

### 方法2：启动时指定环境变量

```bash
# 开发环境
FILE_DOMAIN=http://localhost:3000 mvn spring-boot:run

# 生产环境
FILE_DOMAIN=https://your-domain.com java -jar target/petserver-0.0.1-SNAPSHOT.jar
```

### 方法3：在IDE中配置

在IDEA或Eclipse的运行配置中设置环境变量：
- FILE_UPLOAD_BASE_DIR
- FILE_DOMAIN
- DB_USERNAME
- DB_PASSWORD
- JWT_SECRET

## ⚠️ 注意事项

1. **生产环境部署前**：
   - 修改 `FILE_DOMAIN` 为实际域名
   - 确保 `FILE_UPLOAD_BASE_DIR` 目录存在且有写权限
   - 配置Nginx反向代理和静态资源服务

2. **数据迁移**：
   - 如果已有旧数据，需要更新数据库中的图片URL
   - 可以编写SQL脚本批量更新

3. **安全性**：
   - 不要将 `.env` 文件提交到Git
   - 生产环境使用强密码和密钥

4. **跨域配置**：
   - 如果前后端分离部署，需要配置CORS
