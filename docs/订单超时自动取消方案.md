# 订单超时自动取消方案

## 方案概述

实现待支付订单5分钟超时自动取消功能，包含以下特性：
1. 订单按创建时间降序排序
2. 待支付订单显示倒计时
3. 超时后自动取消订单
4. 前端实时显示剩余时间

## 技术架构

### 后端实现（Spring Boot）

#### 1. 定时任务 - OrderTimeoutTask.java

**位置**: `petserver/src/main/java/com/yellow/petshop/task/OrderTimeoutTask.java`

**功能**:
- 使用 Spring 的 `@Scheduled` 注解实现定时任务
- 每分钟执行一次，检查超时订单
- 自动取消创建时间超过5分钟且状态为 PENDING 的订单

**关键代码**:
```java
@Component
public class OrderTimeoutTask {
    
    private static final int TIMEOUT_MINUTES = 5;
    
    @Scheduled(cron = "0 * * * * ?")  // 每分钟执行
    public void cancelTimeoutOrders() {
        // 计算超时时间点
        LocalDateTime timeoutTime = LocalDateTime.now().minusMinutes(TIMEOUT_MINUTES);
        
        // 查询超时订单
        QueryWrapper<Order> queryWrapper = new QueryWrapper<>();
        queryWrapper.eq("status", "PENDING")
                   .lt("create_time", timeoutTime);
        
        List<Order> timeoutOrders = orderMapper.selectList(queryWrapper);
        
        // 批量取消
        for (Order order : timeoutOrders) {
            order.setStatus("CANCELLED");
            order.setUpdateTime(LocalDateTime.now());
            orderMapper.updateById(order);
        }
    }
}
```

### 前端实现（Vue 3）

#### 1. 订单列表页面 - MyOrdersView.vue

**位置**: `vue-pet/src/views/MyOrdersView.vue`

**新增功能**:

1. **订单排序**: 按创建时间降序排序
```javascript
// 按创建时间降序排序
data.sort((a, b) => {
  return new Date(b.createTime).getTime() - new Date(a.createTime).getTime();
});
```

2. **计算剩余时间**: 为每个待支付订单计算剩余时间
```javascript
const ORDER_TIMEOUT = 5 * 60 * 1000; // 5分钟

data.forEach(order => {
  if (order.status === 'PENDING') {
    const createTime = new Date(order.createTime).getTime();
    const now = Date.now();
    const elapsed = now - createTime;
    order.remainingTime = Math.max(0, ORDER_TIMEOUT - elapsed);
  }
});
```

3. **倒计时显示**: 在订单头部显示倒计时
```vue
<span v-if="order.status === 'PENDING' && order.remainingTime > 0" class="countdown">
  <van-icon name="clock-o" />
  {{ formatCountdown(order.remainingTime) }}
</span>
```

4. **实时更新**: 每秒更新倒计时
```javascript
const startCountdown = () => {
  countdownTimer = setInterval(() => {
    let hasTimeout = false;
    
    orderList.value.forEach(order => {
      if (order.status === 'PENDING' && order.remainingTime > 0) {
        order.remainingTime -= 1000;
        
        if (order.remainingTime <= 0) {
          hasTimeout = true;
        }
      }
    });
    
    // 如果有订单超时，刷新列表
    if (hasTimeout) {
      setTimeout(() => {
        onRefresh();
      }, 1000);
    }
  }, 1000);
};
```

5. **格式化倒计时**: 显示为 "分:秒" 格式
```javascript
const formatCountdown = (milliseconds) => {
  const totalSeconds = Math.floor(milliseconds / 1000);
  const minutes = Math.floor(totalSeconds / 60);
  const seconds = totalSeconds % 60;
  return `${minutes}:${seconds.toString().padStart(2, '0')}`;
};
```

## 工作流程

### 1. 订单创建
- 用户创建订单，状态为 PENDING
- 记录创建时间 `create_time`

### 2. 前端倒计时
- 加载订单列表时，计算每个待支付订单的剩余时间
- 启动定时器，每秒更新倒计时显示
- 倒计时格式：`4:59`, `4:58`, ..., `0:01`, `0:00`
- 超时后显示"已超时"

### 3. 后端自动取消
- 定时任务每分钟执行一次
- 查询创建时间超过5分钟且状态为 PENDING 的订单
- 批量将这些订单状态改为 CANCELLED
- 记录更新时间

### 4. 前端刷新
- 当倒计时归零时，自动刷新订单列表
- 用户会看到订单状态变为"已取消"

## 优势

1. **双重保障**: 前端倒计时 + 后端定时任务，确保订单一定会被取消
2. **用户体验好**: 实时显示剩余时间，用户清楚知道还有多久
3. **性能优化**: 定时任务每分钟执行一次，不会频繁查询数据库
4. **可配置**: 超时时间可以通过常量轻松修改
5. **自动排序**: 订单按创建时间降序，最新订单在最上面

## 注意事项

1. **时区问题**: 确保前后端时间一致，建议使用 UTC 时间
2. **定时器清理**: 组件卸载时必须清除定时器，避免内存泄漏
3. **并发问题**: 后端定时任务使用事务，确保数据一致性
4. **用户提示**: 建议在订单创建时提示用户"请在5分钟内完成支付"
