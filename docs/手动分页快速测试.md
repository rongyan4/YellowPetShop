# 手动分页实现 - 快速测试指南

## ✅ 已完成的修改

### 1. 删除了分页插件配置
- ❌ 删除了 `MybatisPlusConfig.java`（不再需要）
- ✅ 不依赖任何 MyBatis-Plus 分页插件

### 2. Mapper 层添加手动分页方法
```java
// 分页查询
@Select("SELECT * FROM commodity_info LIMIT #{offset}, #{limit}")
List<CommodityInfo> selectByPage(@Param("offset") Long offset, @Param("limit") Long limit);

// 查询总数
@Select("SELECT COUNT(*) FROM commodity_info")
Long selectTotalCount();
```

### 3. Service 层实现手动分页逻辑
```java
// 计算偏移量
Long offset = (current - 1) * size;

// 查询数据
List<CommodityInfo> records = commodityMapper.selectByPage(offset, size);

// 查询总数
Long total = commodityMapper.selectTotalCount();

// 计算总页数
Long pages = (total + size - 1) / size;
```

## 📊 分页原理

### MySQL LIMIT 语法
```sql
SELECT * FROM commodity_info LIMIT offset, limit;
```

### 分页计算
| 页码 | offset计算 | offset值 | 查询范围 |
|------|-----------|---------|---------|
| 第1页 | (1-1)×8 | 0 | 第0-7条 |
| 第2页 | (2-1)×8 | 8 | 第8-15条 |
| 第3页 | (3-1)×8 | 16 | 第16-23条 |

### 总页数计算
```
总页数 = (总记录数 + 每页大小 - 1) / 每页大小
```

例如：
- 总记录数 = 50，每页 = 8
- 总页数 = (50 + 8 - 1) / 8 = 57 / 8 = 7页
