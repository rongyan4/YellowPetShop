# 安装 cropperjs 依赖

## cropperjs 简介

cropperjs 是一个功能强大的图片裁剪库，特点：
- ✅ 完美支持 PC 端和移动端
- ✅ 支持鼠标拖动、缩放
- ✅ 支持触摸操作
- ✅ 高度可定制
- ✅ 零依赖，轻量级
- ✅ 成熟稳定，广泛使用

## 安装步骤

### 1. 安装 cropperjs

在项目根目录执行：

```bash
cd vue-pet
npm install cropperjs
```

### 2. 验证安装

```bash
npm list cropperjs
```

应该看到：
```
vue-pet@0.1.0
└── cropperjs@1.x.x
```

### 3. 重启开发服务器

```bash
npm run serve
```

## 使用说明

### 1. 上传图片
1. 进入商家端 → 商品管理
2. 点击"添加商品"或"编辑"
3. 点击"商品主图"上传区域
4. 选择图片文件

### 2. 裁剪图片
1. 图片加载后自动显示裁剪器
2. 使用鼠标滚轮缩放图片
3. 拖动图片调整位置
4. 拖动裁剪框调整裁剪区域
5. 点击"确定裁剪"保存

### 3. 操作技巧
- **缩放**：鼠标滚轮上下滚动
- **移动**：按住鼠标左键拖动图片
- **调整裁剪框**：拖动裁剪框边角
- **重置**：双击图片切换拖动模式

## 常见问题

### Q1: 图片太大无法显示？
A: 已限制上传文件大小为 5MB，如需更大请修改 `handleFileSelect` 中的限制。

### Q2: 裁剪后图片模糊？
A: 当前输出为 800x800 高质量，如需更高分辨率，修改 `confirmCrop` 中的 width/height。

### Q3: 想要其他比例？
A: 修改 `initCropper` 中的 `aspectRatio` 参数：
- 1:1 → `aspectRatio: 1`
- 16:9 → `aspectRatio: 16/9`
- 4:3 → `aspectRatio: 4/3`
- 自由比例 → `aspectRatio: NaN`

### Q4: 如何禁用某些功能？
A: 在 `initCropper` 配置中修改：
- 禁止移动裁剪框：`cropBoxMovable: false`
- 禁止调整裁剪框：`cropBoxResizable: false`
- 禁止缩放：`zoomable: false`
