## 二、后端控制器重构

### 1. UserController - 头像上传

**修改前**：
```java
@PostMapping("/upload_avatar")
public Result<Map<String, Object>> uploadAvatar(...) {
    // 手动验证文件类型
    // 手动验证文件大小
    // 手动生成文件名
    // 手动保存文件
    // 手动删除旧文件
    // ...约60行代码
}
```

**修改后**：
```java
@PostMapping("/upload_avatar")
public Result<Map<String, Object>> uploadAvatar(
        @RequestParam("file") MultipartFile file,
        @RequestAttribute("userId") Long userId) {
    
    // 使用统一的文件上传工具
    FileUploadUtil.UploadResult result = FileUploadUtil.uploadFile(
        file, 
        FileUploadUtil.BusinessType.USER_AVATAR, 
        userId
    );
    
    if (!result.isSuccess()) {
        return Result.error(result.getMessage());
    }
    
    // 更新数据库
    userService.updateAvatar(userId, result.getImageUrl());
    
    // 返回结果
    Map<String, Object> data = new HashMap<>();
    data.put("avatarUrl", result.getImageUrl());
    data.put("fileName", result.getFileName());
    data.put("fileSize", result.getFileSize());
    data.put("uploadTime", result.getUploadTime());
    
    return Result.success(data);
}
```

**优势**：
- 代码从60行减少到20行
- 逻辑清晰，易于维护
- 自动处理所有验证和文件操作

## 十一、常见问题

### Q1: 为什么要删除商品详情页的"写评价"按钮？
**A**: 
1. 确保评论真实性：只有购买过的用户才能评论
2. 防止恶意评论：避免未购买用户刷评论
3. 提高评论质量：关联订单的评论更有参考价值
4. 符合电商规范：主流电商平台都采用此模式

### Q2: 如何添加新的文件上传业务？
**A**: 只需在 `BusinessType` 枚举中添加新类型，然后在Controller中调用 `FileUploadUtil.uploadFile()` 即可。

### Q3: 如何修改文件大小限制？
**A**: 修改 `BusinessType` 枚举中对应类型的 `maxSize` 参数即可。

### Q4: 旧的图片文件会被删除吗？
**A**: 
- 用户头像：会自动删除旧文件
- 评论图片：不会自动删除
- 商品图片：不会自动删除

### Q5: 如何清理无用的图片文件？
**A**: 可以编写定时任务，定期扫描文件系统和数据库，删除数据库中不存在的图片文件。
